# 小轮腿交接的 Zephyr 依赖

本目录保存 2026-10-24 已烧录小轮腿镜像使用的外部源码版本和已有本地补丁。补丁从原环境导出，没有新增驱动行为；导出后通过 `git apply --check --reverse` 核对已应用内容。

- Zephyr 4.4.0：`684c9e8f32e4373a21098559f748f06915f950c9`。
- Zephyr SDK：本机 `sdk_version` 记录为 `1.0.1`。
- 各模块版本见 `依赖版本.json`；有 `checked_out_commit` 时使用该实际检出版本。
- `manifest-本地驱动补丁.patch` 保存 Zephyr 主仓库中 STM32 串口和 bxCAN 的既有修改。小轮腿 H723 使用 FDCAN，bxCAN 部分用于仓库其他板级。

接收方准备对应 Zephyr 工作区后，在 Zephyr 仓库目录执行（补丁路径按本机位置替换）：

```powershell
git apply --check D:/ARBATOS/tools/build/zephyr/manifest-本地驱动补丁.patch
git apply D:/ARBATOS/tools/build/zephyr/manifest-本地驱动补丁.patch
```

若反向检查通过，说明补丁已经应用，不要重复执行。外部 SDK、Python 环境和 Zephyr 大目录不放进固件及日志压缩包；包内保留现成 ELF/BIN 与构建配置。此记录只解决源码交接，不表示阻尼修正版通过了实物平衡验证。
