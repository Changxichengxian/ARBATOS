# PID 调试流程

PID 调试的前提是反馈可信、方向正确、限幅安全。反馈没确认之前，不要调 PID。

## 基本顺序

1. 先确认电机反馈和控制输出方向。
2. 先调内环，再调外环。
3. 先单轴，再多轴。
4. 先低限幅，再提高限幅。
5. 每次只改一两个参数，并记录效果。

常见双环顺序：

- 云台：速度环 -> 角度环。
- 底盘：单轮速度环 -> 运动学合成 -> 跟随环。
- 射击：摩擦轮速度 -> 拨盘控制。
- 轮腿：单关节 / 单腿 -> 模型参数 -> 平衡控制。

## 先做的安全限制

调 PID 前先把这些限制调保守：

- 最大电流 / 最大力矩。
- 目标速度和目标角度变化率。
- 软限位。
- 遥控安全档。
- 失联保护。
- 运行编排只放行当前要调的子系统。

如果一个参数会让车突然大动作，先不要通过 AUX 临时调参直接大步改。

## 数据入口

| 入口 | 用途 |
|---|---|
| `g_watch` | 快速看在线状态、命令、反馈、错误码 |
| AUX 遥测 | 看少量实时曲线，适合边调边看 |
| SD 日志 | 复盘长时间动作、超时、掉线、限幅原因 |
| `tools/PidAutotune/` | 辅助单环整定，不替代人判断 |
| `RtProf` | 看控制周期是否被日志或通信拖慢 |

调参时至少要能看到：目标值、反馈值、输出值、误差、限幅状态。

## 手动调参建议

### P

P 决定当前误差给多少输出。

- 反应太慢：逐步加 P。
- 开始振荡：P 太大，或者反馈延迟 / 摩擦 / 限幅已经影响闭环。
- 方向一错就发散：不要调 P，先修方向。

### I

I 用来消除稳态误差。

- 长时间差一点到不了目标：小幅加 I。
- 低频来回晃：I 可能太大。
- 输出经常顶限幅：先处理限幅和目标，不要靠 I 硬顶。

### D

D 用来抑制变化，但也会放大噪声。

- 高速接近目标时容易过冲：可以少量加 D。
- 反馈噪声大：先滤波或降低 D。
- 云台 gyro 反馈已经比较直接时，不要盲目加很大的 D。

## 云台

建议顺序：

1. 只开 yaw 或 pitch 单轴。
2. 先确认编码器 / gyro 方向。
3. 调速度环，让速度命令和反馈能跟上。
4. 调角度环，让角度目标不过冲。
5. 加回软限位、运行编排、输入映射。
6. 最后再看视觉、裁判、射击联动。

双 yaw 云台先把下 yaw 调稳，再接上第二 yaw。第二 yaw 的方向、限幅和输出符号要单独确认。

## 底盘

建议顺序：

1. 单个轮子低速输出，确认方向。
2. 四轮分别低速，确认装配顺序。
3. 调单轮速度环。
4. 低速平移和旋转。
5. 再调跟随环。
6. 最后接功率限制和裁判数据。

底盘抖动不一定是 PID 问题，也可能是轮子方向、轮距参数、反馈 ID、底盘坐标系或功率限制在打架。

## 射击

摩擦轮和拨盘分开调。

- 摩擦轮先看速度反馈和启动电流。
- 拨盘先低速空载，确认方向和卡弹保护。
- 有弹测试时先低频，确认热量、裁判数据和卡弹处理。

不要在拨盘反馈和卡弹保护不清楚时直接追求射频。

## 轮腿 / MIT

轮腿调参必须分阶段：

1. 单电机 MIT 模式。
2. 单关节小动作。
3. 单腿离地。
4. 双腿架空。
5. 板凳模型。
6. 落地站立。
7. 平衡和移动。

每个阶段都要留日志。重点看模式、腿长、腿角、关节力矩、轮力矩、IMU 状态、限幅原因和失联保护。

## 记录模板

每次调参至少记：

```text
日期：
Target / Board：
Git / dirty：
子系统：
运行编排：
改动参数：
动作描述：
现象：
SD 日志文件：
下一步：
```

能复盘的调参才算调参。只记“感觉好了”后面很难继续。
