# SENTINEL-M 安装坐标表

这张表说明控制板和主要部件固定在哪个机械坐标上。坐标总口径见 [坐标系和安装基准](../../manual/coordinate-frames.md)。

## 当前结论

| 项目 | 当前定义 |
| --- | --- |
| 控制板 | `DmMc02H7` |
| 控制板固定部件 | 大 yaw 转动部分 |
| INS 姿态主要代表 | 大 yaw 这一级的姿态 |
| 底盘坐标 | `+X` 车体正前，`+Y` 车体左侧，`+Z` 向上 |
| 云台坐标 | `+X` 按当前云台 yaw 的水平朝向，`+Y` 为其左侧 |
| 算法 `q[4]` | 板端姿态参考，按当前安装更接近大 yaw 姿态，不等同于小 yaw 或底盘姿态 |
| 算法 `frame=2` | 按板端估计出的场地基准转到底盘坐标；大 yaw 固定板要特别确认 yaw 基准，不建议默认给算法长期使用 |

## 机械层级

```text
场地
  -> 底盘车体
      -> 大 yaw 转动部分（控制板固定在这一层）
          -> 小 yaw / 上 yaw
              -> pitch / 相机 / 枪管
```

大 yaw 和小 yaw 都会影响“云台看向哪里”。控制板固定在大 yaw 上时，INS yaw 不是底盘 yaw，也不是最终小 yaw 后的完整云台 yaw。

## 控制板方向

| 板轴 | 当前记录 |
| --- | --- |
| 板 `+X` | 待实车确认 |
| 板 `+Y` | 待实车确认 |
| 板 `+Z` | 待实车确认 |

这三行要用实车照片或手动转动确认，不要只凭板子丝印猜。

## 待确认项

- 控制板 `+X/+Y/+Z` 相对大 yaw 部件的具体方向。
- 大 yaw 零位和底盘正前是否重合。
- 小 yaw 零位和大 yaw 正前是否重合。
- 相机光轴、枪管方向和最终云台 `+X` 是否一致。
- `frame=2` 在当前大 yaw 固定板安装下是否应该开放给算法使用。
