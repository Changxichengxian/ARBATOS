# MINIWHEELEG-M 安装坐标表

这张表说明控制板和主要部件固定在哪个机械坐标上。坐标总口径见 [坐标系和安装基准](../../manual/coordinate-frames.md)。

## 当前结论

| 项目 | 当前定义 |
| --- | --- |
| 控制板 | `DmMc02H7` |
| 控制板固定部件 | 轮腿底盘 / 车体 |
| INS 姿态主要代表 | 轮腿底盘姿态 |
| 底盘坐标 | `+X` 车体正前，`+Y` 车体左侧，`+Z` 向上 |
| 云台坐标 | 当前目标没有云台任务，算法移动不应依赖云台坐标 |
| 算法 `q[4]` | 板端姿态参考，按当前安装可理解为轮腿底盘姿态 |
| 算法 `frame=2` | 按轮腿底盘姿态估计出的场地基准转换；没有外部定位时，基准来自上电或融合重置 |

## 机械层级

```text
场地
  -> 轮腿底盘 / 车体（控制板固定在这一层）
      -> 左右腿 / 轮组
```

轮腿控制更关心底盘 pitch、roll、yaw 和轮腿几何，主控板姿态应优先服务底盘/轮腿本体，不按云台解释。

## 待确认项

- 控制板 `+X/+Y/+Z` 相对轮腿底盘的具体方向。
- 板子安装是否有明显倾角，是否需要单独记录安装 pitch/roll 偏置。
- 上电时车头对准场地 `+X` 的流程是否固定。
