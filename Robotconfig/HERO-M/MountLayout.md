# HERO-M 安装坐标表

这张表说明控制板和主要部件固定在哪个机械坐标上。坐标总口径见 [坐标系和安装基准](../../manual/coordinate-frames.md)。

## 当前结论

| 项目 | 当前定义 |
| --- | --- |
| 控制板 | `DmMc02H7` |
| 控制板固定部件 | 单云台本体 |
| INS 姿态主要代表 | 云台姿态 |
| 底盘坐标 | `+X` 车体正前，`+Y` 车体左侧，`+Z` 向上 |
| 云台坐标 | `+X` 按云台 yaw 的水平朝向，`+Y` 为其左侧 |
| 算法 `q[4]` | 板端姿态参考，按当前安装可理解为云台姿态参考 |
| 算法 `frame=2` | 来自板端姿态估计；没有外部定位时，场地基准仍受上电方向和 yaw 漂移影响 |

## 机械层级

```text
场地
  -> 底盘车体
      -> 云台 yaw
          -> pitch / 相机 / 枪管（控制板固定在云台本体上）
```

HERO-M 没有大 yaw / 小 yaw 两级拆分。算法如果按相机或云台朝向移动，优先使用 `frame=0`。

## 待确认项

- 控制板 `+X/+Y/+Z` 相对云台本体的具体方向。
- 云台 yaw 零位和底盘正前是否重合。
- 相机光轴、枪管方向和云台 `+X` 是否一致。
- `q[4]` 是否需要继续保留“姿态参考”表述，还是可以在 HERO-M 上明确为云台姿态。
