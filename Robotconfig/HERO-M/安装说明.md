# HERO-M 安装说明

这张表说明控制板和主要部件固定在哪个机械坐标上。坐标总口径见 [坐标系和安装基准](../../manual/算法协议与坐标.md)。

2026-09-06 22:22 用户实车确认整车运动正常，包括底盘和云台俯仰；2026-09-07 补充明确该反馈范围。当前整车已全部改为 M 板接线，旧 HERO-C 接线不再适用。

## 当前结论

| 项目 | 当前定义 |
| --- | --- |
| 控制板 | `DmMc02H7` |
| 控制板固定部件 | 单云台本体 |
| INS 姿态主要代表 | 云台姿态 |
| 底盘坐标 | `+X` 车体正前，`+Y` 车体左侧，`+Z` 向上 |
| 云台坐标 | `+X` 按云台 yaw 的水平朝向，`+Y` 为其左侧 |
| 算法 `q[4]` | 板端姿态参考，按当前安装可理解为云台姿态参考 |
| 算法 `frame=2` | 来自板端姿态估计；没有外部定位时，场地基准仍受上电方向和 yaw 漂移影响 |

## 机械层级

```text
场地
  -> 底盘车体
      -> 云台 yaw
          -> pitch / 相机 / 枪管（控制板固定在云台本体上）
```

HERO-M 没有大 yaw / 小 yaw 两级拆分。算法如果按相机或云台朝向移动，优先使用 `frame=0`。

## 控制板方向

| 板轴 | 当前记录 |
| --- | --- |
| 安装前方 | 舵机插排侧；24V接线侧朝后 |
| 安装正面 | 元件面朝上，固定在单云台 |
| INS `+X` | 向云台左侧；对应旧HERO俯仰所用旋转轴 |
| INS `+Y` | 向后，即24V接线侧 |
| INS `+Z` | 向上 |

2026-09-06 用户配合抬前沿、水平左转、左沿抬高三项动作，确认旧M板轴变换与此安装不匹配。
本目标使用 `ImuMount.h` 中的传感器到INS变换，本次方向修正仅针对HERO-M，其余现有车型需按各自安装核对。INS坐标沿用既有HERO控制接口，
与整车通用“X前、Y左、Z上”区分：云台俯仰使用 `-INS roll` 和 `-gyroX`，yaw使用 `INS yaw` 和 `gyroZ`。

## 待确认项

- 机械限位的逐项检查；整车正常运动已获用户现场确认，不代替限位专项验收。
- 云台 yaw 零位和底盘正前是否重合。
- 相机光轴、枪管方向和云台 `+X` 是否一致。
- `q[4]` 是否需要继续保留“姿态参考”表述，还是可以在 HERO-M 上明确为云台姿态。
