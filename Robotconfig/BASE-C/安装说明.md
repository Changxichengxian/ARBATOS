# C 板经典车型模板

这是 DJI C 板 STM32F407 的新车配置起点，使用 Zephyr、双 CAN 与板载 BMI088。默认选择经典底盘、普通云台、RM 发射；运行模式为单电机且目标为 `MotorCount`，不释放任何电机输出。

桌面向导选择 C 板后，可勾选普通云台与发射、更换电机型号、选择大疆 DBUS 或 ELRS，以及选择经典底盘功率策略。RM 发射由云台任务调度，需要同时选择普通云台。

## 模板装配

| 机构 | 默认型号 | 总线与节点号 |
| --- | --- | --- |
| 四轮底盘 | M3508 | CAN1，1～4 |
| 云台水平轴、俯仰轴 | GM6020 | CAN2，1、2 |
| 两个摩擦轮 | M3510 | CAN2，1、2 |
| 拨弹 | M2006 | CAN2，3 |

GM6020 的反馈地址从 `0x205` 起，和上述摩擦轮的 `0x201/0x202` 不冲突。节点号仍需在电机硬件上正确设置。

DBUS 默认使用 USART3（PC11 RX）；ELRS 默认改用 USART1（PB7 RX，3.3 V TTL，420000 波特）。裁判系统为 USART6（PG9 RX、PG14 TX）。具体引脚依据仓库现有 C 板设备树，实际接线前须核对板上接口。不要把 ELRS 接到专用 DBUS 接收口；USART1 被接收机占用时不能同时打开串口控制台。

## 内存与调试选择

F407 的普通 RAM 为 128 KiB，另有 64 KiB CCM，用于 CPU 本地数据和任务栈。模板默认关闭完整 Watch 和 SD 日志，不创建对应调试任务；需要日志时在客户端启用 SDLOG 并重新编译。C 板公共动态堆预留为 16 KiB，和静态任务栈分开。实际占用以客户端的“内存与 Flash”及本次构建产物为准。

## 首次上车

PID、几何和输入映射以已有经典控制配置为起点，不表示适配了某台 C 板实车。模板已清除旧车云台编码器中位和旋转前馈；安装方向、软限位和轴方向仍需确认。板载 BMI088 使用六轴融合，当前没有启用 IST8310 磁力计，也没有接入 C 板 IMU 校准值的 Flash 保存。

本模板不开放轮腿、双水平轴云台、PWM 舵机或 RS485 整车组合。软件构建和配置测试不等同于实车验证；确认机械安装、遥控安全档和各电机方向后，再决定运行模式。
