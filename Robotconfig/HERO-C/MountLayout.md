# HERO-C 安装坐标表

这张表说明控制板和主要部件固定在哪个机械坐标上。坐标总口径见 [坐标系和安装基准](../../manual/coordinate-frames.md)。

## 历史接线适用范围

历史提交 `5502578`“引入电机实例装配层（HERO 上车通过）”中的运行正常结论，针对当时的 C 板接线。用户于 2026-09-07 确认：现在这台 HERO 已彻底改为 M 板接线，旧 C 板接线已不适用。此目录保留旧 HERO-C 硬件目标，不能直接套到当前实车；当前安装与接线以 [HERO-M](../HERO-M/MountLayout.md) 为准。

## 当前结论

| 项目 | 当前定义 |
| --- | --- |
| 控制板 | `DjiCF407` |
| 控制板固定部件 | 单云台本体 |
| INS 姿态主要代表 | 云台姿态 |
| 底盘坐标 | `+X` 车体正前，`+Y` 车体左侧，`+Z` 向上 |
| 云台坐标 | `+X` 按云台 yaw 的水平朝向，`+Y` 为其左侧 |
| 算法 `q[4]` | 板端姿态参考，按当前安装可理解为云台姿态参考 |
| 算法 `frame=2` | 来自板端姿态估计；没有外部定位时，场地基准仍受上电方向和 yaw 漂移影响 |

## 机械层级

```text
场地
  -> 底盘车体
      -> 云台 yaw
          -> pitch / 相机 / 枪管（控制板固定在云台本体上）
```

HERO-C 没有大 yaw / 小 yaw 两级拆分。算法如果按相机或云台朝向移动，优先使用 `frame=0`。

## 待确认项

- 控制板 `+X/+Y/+Z` 相对云台本体的具体方向。
- 云台 yaw 零位和底盘正前是否重合。
- 相机光轴、枪管方向和云台 `+X` 是否一致。
- C 板 IMU 磁力计模式是否参与 yaw 零点，影响 `frame=2` 的基准解释。
